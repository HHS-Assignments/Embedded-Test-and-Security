# Opdracht
Schrijf de code voor de testen uit je testplan (wat je vorige week geschreven hebt). Je gebruikt hiervoor het GoogleTests framework.
Mocht je er tijdens het testen achter komen dat je wat vergeten bent in je testplan, mag je dat testplan aanpassen, maar maak de tekst van de aanpassingen een andere kleur, zodat ze duidelijk te onderscheiden zijn. (En nu je les hebt gehad over coverage, weet je vast wat je bent vergeten!)
Vul je tabel ook aan met de resultaten van je testen!!
Aan het eind van het practicum upload je de aangepaste Excel sheet, en de test.cpp file naar Brightspace.
